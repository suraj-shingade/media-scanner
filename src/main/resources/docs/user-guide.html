MediaScanner User Guide

MediaScanner is a high-performance desktop application for organising media files by date.

Getting Started

  1. Select a Source Directory containing your media files.
  2. Select a Target Directory where organised files will be placed.
  3. Choose a Transfer Mode: Copy (safe) or Move.
  4. Click Start Scan or use ⌘↵ / Ctrl+Enter.

Menu Bar

File Menu

  • New Scan — Reset and return to configuration (⌘N)
  • Open Job State… — Resume from a saved checkpoint (⌘O)
  • Quit — Exit the application (⌘Q)

Job Menu

  • Start Scan — Begin processing (⌘↵)
  • Pause — Suspend the running scan (⌘P)
  • Resume — Continue a paused scan (⌘R)
  • Stop — Stop the scan and go to Summary (⌘.)
  • Export Job State… — Save a checkpoint to resume later (⌘E)

View Menu

  • Configuration — Go to the scan setup screen (⌘1)
  • Dashboard — Go to the live progress screen (⌘2)
  • Summary — View the completed job summary (⌘3)
  • Toggle Dark Mode — Switch between light and dark themes (⌘D)

Tools Menu

  • View Failure Report — Open the failure report for the last job
  • Open Log File — Open the application log
  • Clear Hash Cache… — Force re-hashing of all files on the next scan

Preferences

Open via Edit → Preferences… (⌘,) to configure:

  • Performance: Worker thread count, High-Priority Mode
  • Validation: Minimum file size thresholds for images and videos
  • Organisation: Default folder pattern and duplicate policy
  • Ignore Patterns: File patterns to skip during scanning
